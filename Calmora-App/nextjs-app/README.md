# Calmora 🌸

## Overview
**Calmora** is an AI-powered chatbot built to support introverts and people dealing with depression or loneliness.  
It provides a safe space to talk, share feelings, and receive empathetic responses — available anytime.  

In the future, Calmora will also include a **community service** where people with similar interests and personalities can connect, interact, and support each other.

---

## ✨ Features
- 🤖 **AI Chatbot** — Talk naturally with Calmora for companionship and emotional support.  
- 💬 **Contextual Conversations** — Calmora remembers chat history during a session.  
- 🎨 **Clean Interface** — Simple and minimal UI built with Next.js + Tailwind CSS.  
- 🔮 **Future Plans**  
  - Safe community spaces for people with similar interests.  
  - Group discussions and support networks.  
  - Personal growth and mental health resources.  

---

## 🛠️ Tech Stack
- **Frontend**: Next.js + TypeScript  
- **Styling**: Tailwind CSS  
- **AI Integration**: Ollama (using `llama3` by default)  
- **Deployment**: Vercel (frontend) + local Ollama runtime
